# REST API - Cars

REST API developed with C# and .NET for managing car information.

## Technologies

- C#
- .NET
- ASP.NET Core Web API
- SQL Server
- Dapper
- Swagger

## Features

- Get all cars
- Get a car by ID
- Create a car
- Update a car
- Delete a car
- Filter deleted records
- Pagination

## Project Structure

The project follows a layered architecture:

- Controllers
- Services
- Repositories
- Data Access
- DTOs
- Entities

## API Documentation

Swagger is included for testing and exploring the API endpoints.
